- 이유: 토스 앱처럼 단순하고 큰 글씨로 훑어보기 쉬운 느낌을 원했다(로고나 브랜드 요소는 따라 하지 않음). 한 줄 목록은 위에서 아래로 읽기 쉽고, 3단계에서 줄을 눌러 입력하게 할 때 누를 곳도 크다
- 이전: 폰에서 한 줄에 2장인 카드 격자, 왼쪽 색 띠와 🟢·⚪ 이모지로 상태 표시
- 비고: 색은 `src/index.css` 변수로 모았다. 글꼴(Pretendard 등)은 오프라인 동작을 챙겨야 해서 아직 넣지 않았다. 디자인은 나중에 다시 바꿀 수 있다
