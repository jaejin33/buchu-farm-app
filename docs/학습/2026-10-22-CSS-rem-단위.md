# CSS `rem` 단위

앱 하우스 목록 화면(`src/pages/HouseList.css`)의 크기를 `rem`으로 적은 이유와 쓰는 법이다.

**Spring 대응: 없다.** CSS 이야기라 Java·Spring에 대응하는 개념이 없다. HTML/CSS에서 `px`를 써 본 정도면 충분하다.

## 1. `px`와 `rem`

| 단위 | 뜻 | 예 |
|---|---|---|
| `px` | 고정 크기 | `font-size: 30px` → 항상 30픽셀 |
| `rem` | **기준 글자 크기의 몇 배** | 기준이 20px이면 `1.875rem` = 37.5px, 기준이 16px이면 30px |

기준 글자 크기는 페이지 맨 바깥(`:root`, 즉 `<html>`)에 정한 글자 크기다. 이 프로젝트에서는 `src/index.css`에 있다.

```css
:root {
  /* 기준 글자 크기. 화면 전체 크기는 이 숫자 하나로 조정한다 */
  font: 20px/1.4 system-ui, 'Apple SD Gothic Neo', 'Malgun Gothic', sans-serif;
}
```

`20px/1.4`는 "글자 크기 20px, 줄 높이는 글자 크기의 1.4배"라는 줄임 표현이다.

## 2. 왜 `rem`으로 적었나

글자·버튼을 얼마나 크게 할지는 아버지께 직접 보여드린 뒤(5.5단계) 최종으로 정한다. 그때 쉽게 바꿀 수 있게 해 둔 것이다. → [[결정기록]] "화면 크기는 기준 글자 크기 하나로 조정", "화면은 아버지 기준으로 크게"

`px`로 적어 두면 크기를 키울 때 동 번호, 경과 일수 글자, 여백, 카드 폭을 하나하나 다 고쳐야 하고, 비율도 어긋나기 쉽다. `rem`으로 적어 두면 **기준 숫자 한 곳만 바꿔도 전부 같은 비율로 함께 커진다.** 실제로 2.5단계에서 16px → 20px로 올릴 때 `index.css` 한 줄만 바꿨다.

```css
.house-no              { font-size: 1.875rem; }  /* 20px 기준 37.5px (16px 기준이면 30px) */
.house-elapsed strong  { font-size: 1.25rem; }   /* 경과 일수 숫자. 20px 기준 25px */
.house-card            { padding: 0.625rem ...; } /* 여백도 같이 커진다 */
```

## 3. 카드 폭도 `rem`이라 줄 수가 저절로 바뀐다

```css
.house-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(7.5rem, 1fr));
  gap: 0.5rem;
}
```

- `display: grid`: 안의 항목(카드)을 바둑판처럼 놓는다
- `minmax(7.5rem, 1fr)`: 카드 하나는 최소 `7.5rem`(20px 기준 150px)이고, 남는 폭은 카드끼리 똑같이 나눠 가진다(`1fr`)
- `repeat(auto-fill, ...)`: 최소 폭을 지키면서 **한 줄에 들어갈 수 있는 만큼** 놓는다

그래서 한 줄 카드 수는 화면 폭과 기준 글자 크기로 정해진다. (최소 폭 `7.5rem` 기준)

| 화면 | 기준 16px | 기준 20px (지금) |
|---|---|---|
| 폰 (360px 폭) | 한 줄 2장 | 한 줄 2장 |
| 폰 (412px 폭) | 한 줄 3장 | 한 줄 2장 |
| PC (앱 최대 폭 640px) | 한 줄 4장 | 한 줄 3장 |

2.5단계에서 카드에 "수확 후 N일", "약 후 N일" 두 줄이 들어가면서 최소 폭도 `6rem`에서 `7.5rem`으로 넓혔다. 구역 크기(4동, 6동 등)에 맞춘 게 아니라서 PC에서는 구역이 여러 줄로 나뉠 수 있다. 실제로 쓸 화면은 폰이라 PC 줄바꿈은 신경 쓰지 않는다.

## 4. `px`로 남겨 둔 것

테두리 두께(`border-left-width: 6px`), 모서리 둥글기(`border-radius: 10px`), 작은 간격(`margin-left: 2px`)은 `px` 그대로 두었다. 글자가 커져도 두꺼워질 필요가 없는 장식이라서다.

## 5. 직접 해 보기

1. `npm run dev`로 화면을 띄운다 → [[2026-10-22-Vite-개발-서버와-화면-확인]]
2. 브라우저에서 F12 → Ctrl + Shift + M으로 폰 크기로 본다
3. `src/index.css`의 `20px`를 `24px`로 바꾸고 저장한다. 화면이 바로 커지는지 본다. 좁은 폰에서는 한 줄에 1장이 될 수도 있다
4. 확인한 뒤에는 `20px`로 되돌린다
