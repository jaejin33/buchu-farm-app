# CSS `rem` 단위

앱 하우스 목록 화면(`src/pages/HouseList.css`)의 크기를 `rem`으로 적은 이유와 쓰는 법이다.

**Spring 대응: 없다.** CSS 이야기라 Java·Spring에 대응하는 개념이 없다. HTML/CSS에서 `px`를 써 본 정도면 충분하다.

## 1. `px`와 `rem`

| 단위 | 뜻 | 예 |
|---|---|---|
| `px` | 고정 크기 | `font-size: 26px` → 항상 26픽셀 |
| `rem` | **기준 글자 크기의 몇 배** | 기준이 20px이면 `1.3rem` = 26px, 기준이 16px이면 20.8px |

기준 글자 크기는 페이지 맨 바깥(`:root`, 즉 `<html>`)에 정한 글자 크기다. 이 프로젝트에서는 `src/index.css`에 있다.

```css
:root {
  /* 기준 글자 크기. 화면 전체 크기는 이 숫자 하나로 조정한다 */
  font: 20px/1.45 system-ui, -apple-system, 'Apple SD Gothic Neo', 'Malgun Gothic', sans-serif;
}
```

`20px/1.45`는 "글자 크기 20px, 줄 높이는 글자 크기의 1.45배"라는 줄임 표현이다. 뒤의 글꼴 목록은 "앞에서부터 있는 글꼴을 쓴다"는 뜻이다. 아이폰은 Apple SD Gothic Neo, 윈도우 PC는 맑은 고딕(Malgun Gothic)으로 나온다.

## 2. 왜 `rem`으로 적었나

글자·버튼을 얼마나 크게 할지는 아버지께 직접 보여드린 뒤(5.5단계) 최종으로 정한다. 그때 쉽게 바꿀 수 있게 해 둔 것이다. → [[결정기록]] "화면 크기는 기준 글자 크기 하나로 조정", "화면은 아버지 기준으로 크게"

`px`로 적어 두면 크기를 키울 때 동 번호, 경과 일수 글자, 배지, 여백, 칸 너비를 하나하나 다 고쳐야 하고, 비율도 어긋나기 쉽다. `rem`으로 적어 두면 **기준 숫자 한 곳만 바꿔도 전부 같은 비율로 함께 커진다.** 실제로 2.5단계에서 16px → 20px로 올릴 때 `index.css` 한 줄만 바꿨다.

```css
.house-no        { font-size: 1.3rem; }   /* 동 번호. 20px 기준 26px */
.house-main      { font-size: 1rem; }     /* "수확 후 N일". 20px */
.badge           { font-size: 0.8rem; }   /* 배지. 16px — 화면에서 가장 작은 글자 */
.zone            { padding: 1rem 0.9rem 0.3rem; } /* 여백도 같이 커진다 */
.house-row       { grid-template-columns: 2.8rem 1fr auto; } /* 동 번호 칸 너비도 같이 커진다 */
```

**가장 작은 글자는 16px 이상**으로 맞췄다 (`0.8rem` × 20px). 그보다 작으면 폰에서 아버지가 읽기 어렵다. 기준을 낮추면 이 글자도 같이 작아지니, 기준을 바꿀 때 가장 작은 글자가 몇 px이 되는지 계산해 본다.

## 3. 칸 너비를 `rem`으로 적은 이유

한 동 한 줄은 3칸 격자다 ([[2026-10-22-2단계-코드-읽기]] 9번).

```css
.house-row {
  display: grid;
  grid-template-columns: 2.8rem 1fr auto;   /* [동 번호] [수확 후 N일] [배지] */
}
```

동 번호 칸을 `56px`처럼 적었다면, 기준 글자를 키웠을 때 동 번호 글자는 커지는데 칸은 그대로라 "25동"이 칸을 넘친다. `2.8rem`으로 적으면 글자와 칸이 같이 커진다.

대신 화면 폭은 그대로라 **가운데 칸이 좁아진다.** 360px 폭 폰, 기준 20px에서 가운데 칸은 약 130px이다. "수확 후 40일"이 겨우 한 줄에 들어가서, 줄바꿈되지 않게 `white-space: nowrap`을 걸어 두었다. 기준을 더 키우면 배지와 겹치거나 화면 밖으로 밀릴 수 있다.

## 4. `px`로 남겨 둔 것

구분선 두께(`border-top: 1px`), 모서리 둥글기(`border-radius: 20px`, 배지는 `999px`)는 `px` 그대로 두었다. 글자가 커져도 두꺼워지거나 더 둥글어질 필요가 없는 장식이라서다. `999px`는 "충분히 크게" 둥글려 알약 모양을 만드는 관용 표현이다.

## 5. 직접 해 보기

1. `npm run dev`로 화면을 띄운다 → [[2026-10-22-Vite-개발-서버와-화면-확인]]
2. 브라우저에서 F12 → Ctrl + Shift + M으로 폰 크기(360px 폭 기종)로 본다
3. `src/index.css`의 `20px`를 `24px`로 바꾸고 저장한다. 전부 커지는지, 그리고 "수확 후 40일"과 "수확 가능" 배지가 한 줄에 들어가는지 본다
4. 확인한 뒤에는 `20px`로 되돌린다
